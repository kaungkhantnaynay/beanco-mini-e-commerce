# Security Policy

Please do not disclose security vulnerabilities in a public issue.

Report suspected vulnerabilities privately through GitHub's security advisory feature
for this repository. Include the affected component, reproduction steps, impact, and
any suggested mitigation. Do not include real customer data, credentials, or payment
information.

BeanCo is a portfolio and preview deployment unless a release is explicitly marked as
production-ready. Preview environments must not process real payment or customer data.
